# Личная CRM

Приложение, где я веду контакты людей, которых знаю лично. Подробнее - `specs/01-продуктовая-идея.md`.

## Как запустить

### Что нужно установить

- Docker Desktop
- Node.js 24 и pnpm

### Первый запуск

1. Создайте файл `.env` по образцу `.env.example` и заполните значения: логин, пароль, имя базы, порт и строку подключения `DATABASE_URL`.
2. Установите зависимости:

   ```
   pnpm install
   ```

3. Запустите базу данных:

   ```
   docker compose up -d
   ```

4. Создайте таблицы в базе:

   ```
   pnpm db:migrate
   ```

5. Если нужно, заполните базу тестовыми данными (1000 контактов). Команда срабатывает только на пустой базе:

   ```
   pnpm db:seed
   ```

6. Соберите и запустите приложение:

   ```
   pnpm build
   pnpm start
   ```

7. Откройте в браузере http://localhost:3000

### Следующие запуски

1. `docker compose up -d` - запустить базу (если Docker Desktop перезапускался, база поднимется сама).
2. `pnpm start` - запустить приложение.
3. Открыть http://localhost:3000

Остановить приложение: закрыть окно, в котором оно запущено, или нажать Ctrl+C.

### Режим разработки

`pnpm dev` - приложение с автоматической перезагрузкой при изменении кода.

### База данных

- Проверить, что база работает: `docker compose ps`, в колонке STATUS должно быть `healthy`.
- Остановить базу: `docker compose stop`. Данные при этом сохраняются.
- Внимание: команда `docker compose down -v` удаляет все данные базы.
- Схема таблиц - `src/db/schema.ts`. После её изменения: `pnpm db:generate` (создать миграцию), затем `pnpm db:migrate` (применить).
