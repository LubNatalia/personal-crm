# Proposal

## Why

Контактов в CRM много, а смотрю я на них обычно кругами: семья, друзья, теннис, коллеги-аналитики. Сейчас список один, и собрать «всех с тенниса» можно только по памяти. Нужны группы, которые я придумываю сам, причём один человек может быть сразу в нескольких: друг может быть и партнёром по теннису.

## What Changes

- Новая страница «Группы» — на главной кнопка «Группы» рядом с «Добавить контакт». На странице:
  - создать группу;
  - список групп по алфавиту, у каждой — сколько в ней контактов;
  - переименовать и удалить группу. Перед удалением приложение просит подтверждение; контакты при удалении группы остаются в CRM, у них только пропадает эта группа.
- В карточке контакта и на странице «Новый контакт» появляется поле «Группы»: все группы метками, нажатие отмечает или снимает отметку. Отмеченные группы сохраняются вместе с остальными полями кнопкой «Сохранить» или «Добавить контакт». Отмечать можно сколько угодно групп, можно ни одной.
- В том же поле — «Новая группа»: можно создать группу, не уходя со страницы. Она сразу появляется в списке групп и отмечена у этого контакта.
- Название группы обязательно, до 50 символов. Две группы с одинаковым названием быть не может, регистр букв не важен: «Теннис» и «теннис» — одна группа.
- Главная:
  - над списком контактов — фильтр: «Все» и все группы по алфавиту. Выбрал группу — в списке только её контакты. Можно выбрать одну группу за раз. Фильтр работает вместе с поиском по имени и сохраняется в адресе страницы;
  - в строке контакта — метки его групп;
  - строка с количеством показывает, сколько людей в группе;
  - пока выбран фильтр по группе, блок «Пора связаться» скрыт — так же, как во время поиска.
- База: новые таблицы — группы и связи «контакт — группа». У существующих контактов групп нет. На рабочем сервере после выкатки групп нет — создаю их сам.
- Тестовые данные (`pnpm db:seed`, только на пустой базе): группы «Семья», «Друзья», «Знакомые», «Теннис», «Аналитики», часть контактов разложена по ним, некоторые — сразу в две группы.
- Автотесты: в проект добавляется Vitest. Код фичи пишется через TDD: сначала тест, потом код. Тесты, которым нужна база, работают с отдельной тестовой базой в том же локальном Postgres в Docker, без моков.

## Capabilities

### New Capabilities

- `contact-groups`: группы контактов. Создание, переименование и удаление группы, выбор групп в карточке контакта, фильтр по группе и метки групп в списке на главной.

### Modified Capabilities

- `keep-in-touch`: требование «Когда блок скрыт». Блок «Пора связаться» скрыт ещё и тогда, когда на главной выбран фильтр по группе.

Удаление контакта (`contact-deletion`) удаляет его целиком. Его связи с группами исчезают вместе с ним, сами группы остаются, требования этой спеки не меняются.

## Impact

- База: две новые таблицы (`groups`, `contact_groups`), новая миграция Drizzle. Таблица `contacts` и её данные не меняются.
- Код:
  - `src/db/schema.ts`;
  - новый `src/db/groups.ts`: группы — создать, переименовать, удалить, список со счётчиком;
  - `src/db/contacts.ts`: фильтр по группе, группы контакта, сохранение групп вместе с контактом;
  - `src/app/actions.ts`: действия с группами;
  - `src/lib/contact-form.ts`: новое поле формы;
  - новый `src/lib/groups.ts`: проверка названия;
  - `src/components/contact-form.tsx` и новые компоненты в `src/components/`;
  - `src/app/page.tsx`, `src/app/contacts/new/page.tsx`, `src/app/contacts/[id]/page.tsx`;
  - новая страница `src/app/groups/page.tsx`;
  - `src/db/seed.ts`, `README.md`.
- Зависимости: в devDependencies добавляются `vitest` (он уже есть в стеке в CLAUDE.md) и `vite`: Vitest 5 без него не работает. Появляется команда `pnpm test`. Других новых библиотек нет.
- Выкатка обычная: миграция применяется разовым контейнером до старта нового образа.
- Вне рамок:
  - e2e-тесты на Playwright и CI — настраиваем позже, отдельно;
  - цвета и значки групп, порядок групп вручную (всегда по алфавиту);
  - фильтр по нескольким группам сразу;
  - группы внутри групп;
  - группы в блоке «Пора связаться»;
  - действия сразу со многими контактами («добавить выбранных в группу»).
