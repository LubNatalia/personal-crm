# Spec Delta

## MODIFIED Requirements

### Requirement: Правила названия группы

Название группы MUST быть непустым и не длиннее 50 символов. Пробелы в начале и в конце убираются. У одного пользователя две группы с одинаковым названием MUST NOT существовать; регистр букв не важен: «Теннис» и «теннис» — одно название. У разных пользователей одинаковые названия разрешены. Правила одни и те же при создании на странице «Группы», при создании из карточки контакта и при переименовании.

#### Scenario: Пустое название

- **WHEN** пользователь оставляет название пустым или вводит одни пробелы и нажимает «Создать группу»
- **THEN** группа не создаётся, под полем написано «Укажите название»

#### Scenario: Слишком длинное название

- **WHEN** пользователь вводит название из 51 символа
- **THEN** группа не создаётся, под полем написано «Слишком длинно: максимум 50 символов»
- **AND** введённый текст остаётся в поле

#### Scenario: Пробелы по краям

- **WHEN** пользователь вводит «  Теннис  » и создаёт группу
- **THEN** группа называется «Теннис»

#### Scenario: Такая группа уже есть

- **WHEN** у пользователя есть группа «Теннис», и он создаёт группу «теннис»
- **THEN** новая группа не создаётся, под полем написано «Такая группа уже есть»
- **AND** введённый текст остаётся в поле

#### Scenario: Такая группа есть у другого пользователя

- **WHEN** у пользователя A есть группа «Теннис», и пользователь B создаёт группу «Теннис»
- **THEN** группа у B создаётся, ошибки нет, группа A не меняется
